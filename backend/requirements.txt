# Indic-language translation (services/translation.py, indic_processor.py): the LLM
# writes replies in English, and this local IndicTrans2 ONNX model translates them
# into Hindi/Telugu/Tamil/etc. -- verified far more reliable than asking the LLM to
# write those scripts directly. `IndicTransToolkit` (the upstream helper package) only
# ships as a Cython source distribution with no prebuilt wheel, so indic_processor.py
# is a pure-Python reimplementation of its IndicProcessor class instead -- these three
# are its only real dependencies, no compiler needed.
